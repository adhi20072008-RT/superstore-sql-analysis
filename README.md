# Superstore Sales & Customer Analysis Project

This project focuses on analyzing Superstore sales data using SQL to generate business insights related to customer behavior, sales trends, category performance, and customer segmentation.

## Tools & Technologies Used

* MySQL
* SQL
* CSV Dataset
* Data Cleaning & Analysis

## Key Analysis Performed

* Data cleaning and validation
* Null and duplicate checks
* Customer segmentation analysis
* Top customers analysis
* Category-wise revenue analysis
* Monthly sales trend analysis

## SQL Concepts Used

* GROUP BY
* Aggregate Functions
* CASE WHEN
* ORDER BY
* Data Cleaning Queries
* Date Formatting

## Key Insights

* Identified high-value customers based on total sales
* Analyzed category-wise revenue contribution
* Studied monthly sales performance trends
* Segmented customers into different spending groups
